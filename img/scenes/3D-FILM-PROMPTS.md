# 3D animated wedding film: 7 clips

Make each clip in an AI video tool (Kling, Hailuo / MiniMax, Google Veo or Runway).
**Settings:** vertical 9:16, 1080p if you can, 5–8 seconds, no sound needed.
**Rule for every clip:** the signboard or frame must be **empty, with no letters**. Claude writes the names and dates
on it afterwards, so it looks perfect. If the tool adds random text, add "blank signboard, no text, no letters" and try again.

**Style line (paste at the start of every prompt):**
> 3D animated Pixar-style Indian wedding scene, cute stylised characters with big expressive eyes, warm cinematic
> golden lighting, rich detail, smooth gentle camera motion, vertical 9:16, no text, no letters, no watermark.

Save the clips in one folder (for example `Desktop\3d-film\`) named `01.mp4` … `07.mp4`, then tell Claude.

**Tips**
- Make 2–3 versions of each clip and keep the best one.
- To keep the same couple and parents in every clip, use the tool's "image to video" option: first make one good
  picture of each scene (ChatGPT or Gemini, same style line), then animate that picture.
- 1080 × 1920 or larger keeps it sharp on phones.
